# 01_Weekly

00_Daily フォルダの内容をもとに、毎週日曜日の夜(23:00 JST)に自動生成される週次まとめを格納するフォルダです。

## ファイル命名規則

`YYYY-MM-DD_YYYY-MM-DD.md` (月曜日の日付_日曜日の日付、例: `2026-09-07_2026-09-13.md`)

## 生成の仕組み

Claude Code のスケジュール実行(Routine)が毎週日曜 23:00 JST に起動し、その週(月〜日)の
`00_Daily/YYYY-MM-DD.md` を読み込んでまとめを作成し、main ブランチへ直接コミット・push します。

フォーマットは `_template.md` を参照してください。
